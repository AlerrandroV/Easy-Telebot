# Упрощённый Python

**Языки:** [Português (Brasil)](pt-BR.md) · [English (US)](en-US.md) · [Español (México)](es-MX.md) · [Français](fr.md) · Русский

Упрощённый Python — это часть Python для тех, кто не программирует. Вы пишете несколько
строк, и бот решает, что ответить: «если человек прислал фото, сделай это; иначе — то».
Код выполняется прямо на телефоне, внутри приложения, с ограничениями безопасности: он не
трогает файлы телефона и сам не выходит в интернет. Для этого есть `termux()`.

Имена работают на **русском, португальском, английском, испанском и французском**
одновременно. Только слова самого Python остаются английскими: `if`, `elif`, `else`,
`for`, `in`, `while`, `break`, `continue`, `and`, `or`, `not`, `True`, `False` и `None`.

> Пока что приложение доступно на португальском и английском. Русские имена
> упрощённого Python работают при любом языке приложения.

## Где использовать

- **Блок «Упрощённый Python»** (в приложении: *Python*) в
  команде: нажмите *Добавить* и выберите блок. Код выполняется, когда кто-то использует
  команду. `стоп()` отменяет блоки, идущие после него.
- **Блок «Ждать ответа»** (*Wait for reply* / *Aguardar resposta*): в меню с тремя точками
  выберите Python. Код выполняется **на каждое сообщение** человека (и на каждую нажатую
  кнопку без собственного ответа), пока код не вызовет `стоп()`. Если человек отправит
  команду, ожидание отменяется.

Редактор проверяет код во время набора и объясняет каждую ошибку с номером строки.
Кнопка отступа добавляет 4 пробела, а Enter повторяет отступ строки выше (плюс 4 пробела
после строки, которая заканчивается на `:`).

## Пример: смена фото профиля через Termux

Команда `/foto` с двумя блоками: сообщение «Пришлите новое фото» и *Ждать ответа* с
таким кодом:

```python
if сообщение.тип == фото:
    файл = сообщение.фото.скачать()
    р = termux("node obnovit_foto.js", файл, время=60)
    if р.ок:
        отправить_текст("Фото успешно обновлено!")
    else:
        отправить_текст("Не получилось: " + р.ошибка)
    стоп()  # ожидание закончено
else:
    отправить_текст("Это не изображение. Пожалуйста, пришлите фото!")
```

Пока человек присылает что-то другое, бот снова просит фото. Когда приходит фото,
приложение скачивает файл, передаёт его скрипту в Termux и завершает ожидание.

## Основы

- Всё, что **внутри** `if`, `else`, `for` или `while`, пишется с 4 дополнительными пробелами в начале строки.
- Текст — в кавычках: `"Привет"`. Склеить текст: `"Привет, " + пользователь.имя`.
- Чтобы вставить значения в текст, используйте f-строку: `f"Привет, {пользователь.имя}!"`.
- Сравнение: `==` (равно), `!=` (не равно), `<`, `>`, `<=`, `>=`, `in` (входит в).
- Переменные: `всего = 3`, потом `всего = всего + 1` (или `всего += 1`).
- Списки `["а", "б"]`, словари `{"ключ": "значение"}`, `for элемент in список:`.
- Комментарии начинаются с `#`.

В упрощённом Python нет: `import`, `def`, `class`, `try`, `with`, `lambda`,
`[x for x in ...]` и имён, начинающихся с `_`. Разрешённые встроенные функции: `len`,
`str`, `int`, `float`, `bool`, `round`, `abs`, `min`, `max`, `sum`, `range`, `list`,
`dict`, `tuple`, `set`, `sorted`, `reversed`, `enumerate`, `zip`, `any` и `all`, а также
обычные методы текста (`.lower()`, `.split()`, `.replace()`…), списков (`.append()`…) и
словарей (`.get()`…).

## Что видит код

| Имя | Что это |
|---|---|
| `сообщение.тип` | Тип сообщения: `текст`, `фото`, `видео`, `гиф`, `аудио`, `голосовое`, `документ`, `стикер`, `геопозиция`, `контакт`, `опрос`, `кнопка` или `другое`. Можно сравнивать с кавычками и без: `сообщение.тип == фото` или `== "фото"` |
| `сообщение.текст` | Текст (или подпись к медиа) |
| `сообщение.фото` | Фото (в наибольшем разрешении) или ничего, если это не фото |
| `сообщение.файл` | Любое медиа: фото, видео, аудио, документ, стикер… |
| `сообщение.данные` | Данные нажатой кнопки (когда `сообщение.тип == кнопка`) |
| `сообщение.контакт` | Телефон из присланного контакта |
| `сообщение.широта`, `сообщение.долгота` | Присланная геопозиция |
| `файл.скачать()` | Скачивает файл на телефон; возвращает тот же файл, теперь с `путь` |
| `файл.имя`, `файл.размер`, `файл.формат`, `файл.id` | Данные файла |
| `пользователь.имя`, `пользователь.фамилия`, `пользователь.логин`, `пользователь.id`, `пользователь.язык` | Кто отправил |
| `пользователь.админ` | `True`, если человек — администратор бота |
| `чат.id`, `чат.тип`, `чат.название`, `чат.личный` | Куда пришло сообщение |
| `аргументы` | Текст после команды (`/скажи привет` → `"привет"`) |
| `переменные` | Словарь, который хранится для каждого человека: `переменные["город"] = сообщение.текст`. Латинские имена (`переменные["city"]`) также работают как `{city}` в обычных сообщениях |

## Функции бота

| Функция | Что делает |
|---|---|
| `отправить_текст(текст, кнопки=[...])` | Отправляет сообщение. Понимает *жирный*, _курсив_, [ссылка](site.ru)… |
| `ответить(текст)` | То же, но ответом на сообщение человека |
| `отправить_фото(фото, подпись="")` | Фото по ссылке, по `файл` или по пути |
| `отправить_файл(путь, подпись="")` | Отправляет документ |
| `кнопка("Текст", ссылка=..., данные=..., копировать=...)` | Создаёт кнопку: ссылка, данные (callback) или копирование текста |
| `termux(команда, арг1, арг2, ..., время=30, ждать=True, окружение={})` | Запускает команду в Termux (см. ниже) |
| `стоп()` | Завершает код. В *Ждать ответа* — завершает ожидание |
| `пауза(секунды)` | Немного ждёт (всего до 60 с за запуск) |
| `журнал(...)` | Пишет в журнал (логи) приложения |
| `base64(файл_или_текст)` | Переводит в base64 |
| `случайное(1, 6)` | Случайное число от 1 до 6 |
| `выбрать(список)` | Случайный элемент списка |
| `сейчас()` | Дата и время телефона: `"25/11/2026 14:30"` (день/месяц/год) |
| `напомнить(когда_и_текст)` | Ставит напоминание отправителю: `напомнить("25/12 10:00 позвонить бабушке")` или `напомнить(30, "достать пирог")` (минуты). Даты словами понимаются на португальском и английском ("tomorrow 9am…"). Возвращает, когда напомнит, или пустую строку, если не понял |
| `отменить_напоминания()` | Удаляет ожидающие напоминания отправителя и говорит, сколько их было |

Все функции отправки принимают `кому=ID_ЧАТА` (или `кому="@канал"`), чтобы отправить в другой чат, например в расписании без получателя.

### Кнопки

```python
отправить_текст("Понравилось?", кнопки=[
    [кнопка("Да", данные="da"), кнопка("Нет", данные="net")],
    кнопка("Сайт", ссылка="https://example.com"),
    кнопка("Скопировать промокод", копировать="PROMO10"),
])
```

Список кнопок ставит по одной в строку; список внутри списка — это строка из нескольких
кнопок. Если у кнопки нет ответа, настроенного в приложении, нажатие попадает в
*Ждать ответа* с кодом:

```python
if сообщение.тип == кнопка:
    отправить_текст("Вы выбрали: " + сообщение.данные)
    стоп()
```

### `termux()`

```python
р = termux("python3 ~/bot/pogoda.py", аргументы, время=20)
отправить_текст(р.вывод if р.ок else "Ошибка: " + р.ошибка)
```

- Каждый аргумент безопасно заключается в кавычки для shell. **Файл** (`сообщение.фото`,
  `файл`…) скачивается и копируется в Termux; скрипт получает путь к нему (до 512 КБ на
  файл; нужен Termux 0.118 или новее).
- `время`: сколько секунд ждать результат (от 1 до 300; по умолчанию 30).
- `ждать=False`: выполняется в фоне без ожидания; `termux()` ничего не возвращает.
- `окружение={"GOROD": "Moskva"}`: дополнительные переменные окружения (имена — латинские
  ЗАГЛАВНЫЕ буквы). Скрипт получает и обычные: `TELEBOT_ARGS`, `TELEBOT_UPDATE`,
  `TELEBOT_CHAT_ID`, `TELEBOT_USER_ID`…
- У результата есть `р.ок` (получилось), `р.вывод` (что напечатал скрипт), `р.ошибка`
  (stderr или причина сбоя), `р.код` (код выхода) и `р.время_вышло`.

Termux должен быть настроен: см. *Termux и скрипты* на экране бота.

## Ограничения (чтобы бот никогда не зависал)

- 200 000 шагов и 10 секунд обработки за запуск (ожидание Termux, Telegram или паузы не
  считается). `while True:` без `break` остановится здесь.
- 20 сообщений за запуск; текст до 100 000 символов; списки до 10 000 элементов.
- Код до 20 000 символов; `переменные` до 64 КБ на человека.

Если что-то пошло не так, ошибка появляется в журнале приложения с номером строки и
объяснением — на языке, на котором написан код.
